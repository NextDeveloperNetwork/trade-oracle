# 🤖 Autonomous Trading Engine — Usage Guide

## Overview

This is a real-time cryptocurrency trading command center built on Binance WebSocket streams.
It supports **10 different bot strategies**, live & simulated trading, manual execution, asset triangulation, and a full signal/trade log.

---

## 🧠 Bot Strategies

Select a strategy from the **Bot Selector** panel on the dashboard. Each strategy uses a different mathematical model to generate BUY/SELL signals.

---

### 🟢 LOW RISK

| Bot | Logic | Best For |
|-----|-------|----------|
| **EMA Scalper** | 5/30 EMA crossover — fires when the short average crosses the long average | Quick momentum bursts, most active coins |
| **Trend Follower** | Measures the total % change over the last 10 price ticks | Steady, sustained market rallies or sell-offs |
| **VWAP Trader** | Compares current price to a 50-tick approximated VWAP; buys below, sells above | Range-bound markets, stable pairs |

---

### 🟡 MEDIUM RISK

| Bot | Logic | Best For |
|-----|-------|----------|
| **Mean Reversion** | Buys when price is >0.8% below the 50-period mean; sells when >0.8% above | Flash crashes, pump reversals |
| **Breakout Hunter** | Fires when price breaks above the 20-period high or below the 20-period low | Consolidation breakouts, range escapes |
| **RSI Momentum** | Uses RSI(14); BUY when RSI < 35 (oversold), SELL when RSI > 65 (overbought) | Catching exhausted moves |
| **Swing Trader** | Combines 12/50 EMA cross with Bollinger Band confirmation (2σ) | Medium-term swings, 10–30 minute holds |

---

### 🔴 HIGH RISK / HIGH REWARD

| Bot | Logic | Best For |
|-----|-------|----------|
| **Aggressive Bot** | 3/20 EMA cross combined with RSI filter — very sensitive, frequent signals | Maximum signal frequency, volatile markets |
| **Hyper Scalper** | 2-tick vs 8-tick average momentum + RSI double filter — ultra high-frequency | Extreme volatility, micro-scalping |
| **Sniper Bot** | Fires ONLY at Bollinger Band extremes (2.5σ) combined with RSI < 30 or > 70 — rare but powerful | Catching the absolute top or bottom of a move |

> ⚠️ **High Risk bots signal more frequently and trade larger proportions of your balance.** Use with caution on real accounts.

## ⚙️ Dynamic Position Sizing

When **Auto-Trading** is active, the bot does NOT use a fixed trade size. Instead, it calculates confidence dynamically:

```
Confidence = clamp(|shortMA - longMA| / longMA × 80, min, max)
```

- **LOW/MED risk bots**: 25%–90% of available USDT balance
- **HIGH risk bots** (Aggressive, Hyper, Sniper): 50%–92% of available USDT balance
- Minimum order: **$1 USDT** (to avoid dust trades)
- **Cooldown**: 15 seconds between auto-executed trades per coin

## 📋 Dashboard Panels

### Market Cards
- Live price feed via Binance WebSocket
- Current BUY/SELL/HOLD signal badge per coin
- 24h gain percentage
- Manual BUY/SELL buttons using the selected trade size

### Trade Size Bar
- Quick presets: **$10 / $50 / $100 / $500 / MAX**
- MAX uses your entire available USDT balance

### Signal & Trade Log
- **Signals tab**: Shows every signal generated by the bot (max 50)
- **Trades tab**: Shows every executed trade (max 50)
- **Download button**: Exports active tab as a `.csv` file

### Holdings Table
- Shows all coins with a non-zero balance
- Click any row to auto-populate the **Triangulation Tool** source field

### Triangulation Tool (Instant Convert)
- Convert any asset directly to any other
- Supports USDT ↔ Crypto and Crypto ↔ Crypto
- Click an asset in the Holdings Table to pre-fill it

## 🔴 Live Mode vs 🔵 Simulator

| Mode | Description |
|------|-------------|
| **Simulator** (Blue) | All trades are paper trades — real prices, simulated balances |
| **Live Binance** (Orange) | Executes real orders via your Binance API keys in `.env` |

> Always test a strategy in **Simulator** mode before enabling Live Mode.

---

## 🛡️ API Keys Setup

Add your Binance API keys to the `.env` file in the project root:

```
BINANCE_API_KEY=your_api_key_here
BINANCE_SECRET_KEY=your_secret_key_here
```

> **Never commit your `.env` file.** It is already listed in `.gitignore`.

---

## 🚀 Quick Start

1. Open the dashboard at `http://localhost:3000`
2. Add coins from **Markets → Watchlist**
3. Select a **Bot Strategy** from the selector panel
4. Set your desired **Trade Size**
5. Enable **Auto-Trading** (⚡ button) to let the bot trade automatically
6. Monitor signals in the **Log Panel** on the right
